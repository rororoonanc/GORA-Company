Place your images in this folder using these exact file names:

  gora logo.png   -> navbar, footer, preloader and favicon
  hero.jpg        -> hero section (portrait, about 4:5, e.g. 1200 x 1500 px)
  about.jpg       -> about section (about 8:7, e.g. 1200 x 1050 px)
  product1.jpg    -> carousel slide 1 (landscape 16:10, e.g. 1600 x 1000 px)
  product2.jpg    -> carousel slide 2
  product3.jpg    -> carousel slide 3

If a file is missing, the site shows a beige placeholder instead.
To add more carousel slides, copy a <figure class="carousel__slide"> block in index.html.
